# Подключение заявок
Новый токен хранится только в серверной переменной TELEGRAM_BOT_TOKEN.
TELEGRAM_CHAT_ID — ID личного чата Сергея с ботом, не имя пользователя.
После запуска бота владельцем чата ID можно получить из Bot API getUpdates.
Для публикации обе переменные нужно добавить как секреты Sites и выпустить новую версию.
В .env можно ввести значения для локальной проверки; файл исключён из Git.
Без настроенных секретов форма возвращает ошибку и предлагает прямую связь. Она не имитирует успешную отправку.
3D-модель — реконструкция по фото, требует сверки с чертежом производителя.
Перед открытием сайта для покупателей уточнить нагрузку, фиксацию, сроки и гарантию.
